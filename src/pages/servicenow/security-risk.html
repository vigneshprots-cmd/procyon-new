What does ServiceNow Security Operations include?

Vulnerability Response with a risk priority model, Security Incident Response for SOC orchestration, and continuous compliance, all on the same CMDB as IT operations.

Which security tools does it integrate with?

Commonly CrowdStrike Falcon, Splunk, Microsoft Sentinel, Tenable, Qualys, Rapid7, Okta and Palo Alto XSOAR.

Which compliance frameworks are supported?

Controls and audit workflows are built for HIPAA, NIST, FedRAMP, SOC 2 and Judicial Council standards, among others.

Does Procyon offer managed security services?

Yes. Beyond ServiceNow, Procyon offers SOC in a Box for 24x7 managed detection and response, continuous GRC and security assessments.
