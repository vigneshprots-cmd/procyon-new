Asked before building a knowledge assistant.

What is a RAG knowledge assistant?

A retrieval-augmented generation assistant searches approved company documents for the passages relevant to a question, then has a language model answer from only those passages, with the source cited. It answers from company knowledge rather than from the model's general memory.

How do knowledge assistants avoid hallucinations?

Answers are generated only from retrieved, approved documents, every answer cites its source, guardrails filter unsafe output, and questions below a confidence threshold are handed to a person.

Which document sources can be connected?

Commonly SharePoint, Salesforce Knowledge, ServiceNow knowledge bases, Confluence and PDF libraries. The Enterprise RAG Starter includes connectors for Salesforce Knowledge, SharePoint and PDFs.

Can the assistant respect document permissions?

Yes. Retrieval is permission-aware and mirrors existing access rights, so each user only gets answers from documents they are already allowed to see.

How long does a knowledge assistant take to build?

Starting from the Enterprise RAG Starter, production generative AI use cases typically reach first value in about 8 weeks, depending on the number of sources and the review needed.
